# Vita Sana by Karin

Landing page jogového štúdia **Vita Sana by Karin** — statický web
(Tailwind CSS cez CDN, FontAwesome, Google Fonts). Bez build kroku.

- **Jogové štúdio:** J. C. Hronského 389/4, Zvolen

## Obsah
Hero · Piliere (joga / arteterapia / ajurvédska a marocká gastronómia) · 4 interaktívne
lekcie jogy · praktické info · pobyty (`pobyty.html`) · Google mapa · rezervačný modal formulár · footer.

## Spustenie
Otvor `index.html` v prehliadači.

## Ešte doplniť
- reálny telefón a e-mail (teraz `+421 905 123 456`, `info@vitasana.sk`)
- otváracie hodiny štúdia
