# Vita Sana by Karin

Landing page jogového štúdia a salónu **Vita Sana by Karin** — jeden statický HTML súbor
(Tailwind CSS cez CDN, FontAwesome, Google Fonts). Bez build kroku.

- **Jogové štúdio:** J. C. Hronského 4
- **Salón:** Somolického 2

## Obsah
Hero · Piliere (joga / arteterapia / ajurvédska a marocká gastronómia) · 4 interaktívne
lekcie jogy · praktické info · dve lokality · rezervačný modal formulár · footer.

## Spustenie
Otvor `index.html` v prehliadači.
